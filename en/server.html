Aether SERVER

Aether on your own infrastructure

Run Aether on your own server or cloud infrastructure managed by your organisation. The team works in a browser, while issues and attachments stay in your environment.

What you decide with a self-hosted installation

Data location

Choose where the application, database and attachments run.

Information access

Define access to the instance, then project roles and permissions.

Updates

Your administrator schedules updates under your organisation's operational policies.

Backups and recovery

Set a backup schedule and a way to test whether the environment can be restored.

From installation to your first project

  1. 1

    Prepare the environment

    An application server, PostgreSQL 17 or 18, attachment storage and HTTPS access for users.

  2. 2

    Configure Aether

    Use the installation wizard or file-based configuration. Prepare the administrator account and instance settings.

  3. 3

    Invite the team

    Create a project, choose a workflow and board, grant access and start working with issues.

Maintaining Aether Server

With the Server edition, your organisation maintains infrastructure, updates, monitoring, database and attachment backups, and recovery tests. Self-hosting lets you apply your own security policies and requires you to keep them in place.
