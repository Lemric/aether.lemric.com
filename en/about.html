ABOUT LEMRIC

Aether is built by Lemric.

Aether Lemric is a new product, built on our experience in developing software, libraries and user interfaces.

A tool for everyday project work

Lemric / Aether

Sprint plans, task discussions and time records relate to the same work. In Aether, we connect them to issues so a project review can return to both the plan and what happened during delivery.

For some teams, where information is stored matters too. The Server edition supports installation in an environment managed by your own organisation.

01

Different views of the same issues

Lists, boards and issue details use the same project data. Each view supports a different part of the team’s work.

02

Configurable processes and access

Set states, transitions and permissions in configuration. Each project can have its own delivery and access rules.

03

Lemric libraries and DesignSystem

We use our own Lemric libraries and Lemric DesignSystem. Shared interface components are used in Aether and other Lemric products.
