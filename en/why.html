WHY Aether LEMRIC

Why Aether Lemric

A project management tool shapes the team's daily work. Aether brings issues, planning and time records together with installation in your own environment.

01

You want to see the whole path of a task

A task list is a starting point. Boards show the flow of work, workflows define the next step, and comments and history preserve decisions. See the current state and the path that led there.

02

Your team has its own working rules

Some projects need more than moving a card to done. Custom states, transitions and required fields accommodate review, approval and completion requirements.

03

You want to choose where data lives

Aether Server runs on infrastructure managed by your organisation. You set the policies for access, storage, updates and backups.

04

You need clear responsibilities

Owning a task, accessing a project and editing an issue are different responsibilities. Roles, groups and permission schemes help keep them distinct.

05

You want to connect the plan with actual work

Sprints and releases describe the plan. States, reports and time entries show delivery. In Aether, this information relates to the same issues.

06

You already have data and tools

Import dry runs help you evaluate moving issues. The REST API and extensions support connections to the other parts of your working environment.
